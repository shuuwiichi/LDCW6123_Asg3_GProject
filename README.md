# LDCW6123_Asg3_GProject
Group project for LDCW6123 Assignment 3
movies.py           → raw movie data
logic.py            → scoring rules (if/elif matching + weighted score)
recommender.py      → turns scores into full recommendation results (with reasons)
similarity.py       → fuzzy-matches mistyped user input to valid options
names.py            → internal code → display-friendly label lookup
history.py          → saves/loads past searches to/from a JSON file
main.py             → user interface (menu, input, printing results)
